# Admin 3.11.0 — Usuários do Portal do Cliente

1. Implante o Worker v1.17.0.
2. Publique os arquivos desta pasta na raiz do repositório atual do Admin.
3. Pressione `Ctrl + F5`.
4. Entre no Admin e abra **Gestão Comercial**.
5. Na tabela de clientes, clique em **Usuários**.
6. A conta principal aparece protegida.
7. Use **Novo usuário** para criar contas adicionais e copie a senha temporária.

O Portal Público/PWA, o firmware e os dados oficiais não são modificados por esta atualização.
