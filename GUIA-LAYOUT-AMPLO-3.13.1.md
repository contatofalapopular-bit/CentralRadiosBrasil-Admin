# Admin 3.13.1 — Layout Amplo Global

## Objetivo
Aproveitar melhor a largura da tela em todos os módulos, reduzindo o espaço ocupado pelo menu lateral e as margens internas.

## Alterações
- menu lateral: 280 px → 224 px no desktop;
- conteúdo central sem limite fixo de largura;
- margens internas reduzidas;
- tabelas de Qualidade e Audiência compactadas;
- responsividade móvel preservada.

## Instalação
1. Extraia o ZIP completo.
2. Envie todos os arquivos internos para a raiz do repositório do Admin.
3. Faça o commit.
4. Aguarde o GitHub Pages concluir.
5. Atualize com Ctrl + Shift + R.
6. Confirme a versão 3.13.1 no rodapé.

## Rollback
O pacote completo inclui a versão 3.13.0 integral na pasta de rollback.
